# **App Name**: Staff Hub

## Core Features:

- Secure Login: User authentication and authorization.
- Employee Directory: Display employee directory with search and filter options.
- Employee Profiles: Capture essential employee data.
- AI Powered Sentiment Tool: AI tool: Sentiment analysis of employee feedback forms and HR related written reports; providing a flag to admins when serious action is required based on negative tone/language used.
- Shared Calendar: A shared calendar for leave and public holidays
- Detailed profiles: Display contact info, department, and roles for each employee

## Style Guidelines:

- Primary color: Deep teal (#136F63) for a professional and trustworthy feel.
- Background color: Light teal (#D2E9E6), a very low saturation version of the primary color.
- Accent color: Soft purple (#877795), a subtle contrast that retains professionalism.
- Body and headline font: 'Inter', a grotesque-style sans-serif.
- Use simple, clear icons from a consistent set to represent departments, roles, and actions.
- A clean, card-based layout for employee profiles and directory listings.
- Subtle transitions and hover effects to enhance usability without being distracting.
